# AI Infra：我的学习与实践

从一个小程序、一块 Tensor 和一次请求开始，逐步弄清 AI Infra 怎样计算、搬运数据、提供服务和安排任务。这里保存讲解、练习，也保存我自己的思考与真实结果。

- **第一次开始：** 打开 [基础自测](course/prerequisites.md)。Python 核心还不熟，就从 [P1：函数与变量](course/foundations/p01.md) 开始。
- **继续学习：** 从 [我的进度](course/progress.md) 回到当前内容，按课页底部的下一步推进。
- **查看全程：** [完整课程目录](course/README.md) · [视频与资料](resources/README.md)。

每节先提出一个问题，再结合例子和图推演，最后自己动手核对。试着换一组输入、修复一个错误；能解释原因并独立做出来，再继续下一节。时间只帮助安排日历。
