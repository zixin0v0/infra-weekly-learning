# 从空文件写一个统计小工具

先完成 P1～P7。本题的函数和入口由自己组织，允许查标准库接口，不复制 summary_start 的完整实现。

要让工具换文件后还能运行，先把输入位置从代码里移到命令行。输入文件保存 UTF-8 JSON 数值数组；`--input` 与 `--output` 必填，`--config` 可选。配置文件可给 scale，命令行 --scale 优先于配置，未提供时为 1。先应用 scale，再计算 count、sum、mean。

输出：JSON 对象，包含 count、sum、mean。空数组或非数值输入明确报错，退出码非零，不写假成功结果。输入与输出路径不得相同；输入文件保持不变。日志写 stderr，结果文件只含数据。

检查：原输入 [2,4,6]；负数 [-2,0,5]；单元素 [7]；空数组；字符串混入；路径不存在；包含中文或空格的目录。每次先写预期结果或错误，再运行并保存实际输出。生成的结果放进 labs 的 results 内。

完成后用新的终端进程重读结果，解释参数、配置、函数、文件、异常和测试如何连接。再换一组未见输入独立重跑。
