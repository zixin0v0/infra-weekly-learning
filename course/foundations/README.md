# 编程基础：从读懂程序到独立完成小工具

[总路线](../../README.md) · [先修诊断](../prerequisites.md) · [资源索引](../../resources/foundations.md#p-py) · [能力检查](README.md#foundation)

从你已有的数学基础出发，把一次计算写成函数，再逐步给它加上输入检查、文件读写和测试。最终，你会从空文件完成一个能反复运行的统计工具。先完成 P1～P7，再进入 W1；P8 的对象与类在 W6 前完成。Linux、C++、Tensor 和训练分别在下方规定的位置衔接。不按用时判定完成。

主教材为 Harvard CS50P 的 0～6、8 单元：每次先看对应课程讲解或读官方 Notes，再做各节的本地练习。优先看每段的直接视频入口，Notes 用于回查；视频无法使用时按指定 Notes 范围继续。尚未核验的分钟数不填写。这里选学课程内容，不要求注册、提交官方作业或取得证书，也不等同于完成整门 CS50P。

各段先看指定视频主题或对应正文，逐行解释例子，再补全步骤、独立重写、改变条件、排查错误。遮住折叠答案后作答。代码题在自己的 `labs/00-foundations/` 动手时创建文件，记录保存在同目录 `notes.md`，段号 P1～P8。以下数字都是练习参考值，未代表你的运行结果。

## 入口与预计用时

| 阶段 | 首次学习的参考范围 | 进入下一阶段的条件 |
| --- | --- | --- |
| P1～P3：表达、分支、循环 | 8～16 小时 | 能用函数处理一组输入，并说明每一步 |
| P4～P6：错误、模块、文件 | 10～20 小时 | 能定位失败，从文件读取并保存结果 |
| P7：测试与独立小工具 | 6～12 小时 | 不复制完整答案完成工具，边界检查通过 |
| P8：对象与类 | 4～8 小时，在 W6 前完成 | 能解释实例状态，并理解模型的构造与调用 |

以上只帮助安排学习次数；实际需要更久就继续。如果已经能独立通过对应检查，可以跳过讲解，把解法和结果留在笔记里。不要把这些范围与同一材料的视频时长再次相加。

## 基础检查后去哪里

P1～P7 通过后，完成 [先修 B 的最小 C++/Tensor 与 M1](../prerequisites.md)，再进入 [W1](../../weeks/week-01-foundations/README.md)。P8 可以现在接着学，也可以在 W6 前补齐；之后沿 [单卡训练课](training.md) 完成训练、验证和重载。
