## 从线程分组回到硬件

某虚构 SM 最多容纳 32 warp、64 KiB shared，每 block 256 线程并用 32 KiB shared，假设其他限制不约束。预测最多驻留的 block 数和 occupancy。若改用更多 shared 得到更高数据复用，是否必然更慢？

<details><summary>核对资源约束</summary>

shared 限制为 2 block；每 block 8 warp，共 16 warp，occupancy 为 50%。更多 shared 可能减少驻留 block，也可能减少显存访问，最终需计时和访存证据。不能用 occupancy 单项替代性能，也不能将 block 数认作 SM 数。回 [硬件关系图](session-01.md)。

</details>
