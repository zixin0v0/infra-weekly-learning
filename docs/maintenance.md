## 记录约定

一次实验在 labs 中保存 README、notes、代码、必要配置与环境摘要。真实测量按 results/YYYY-MM-DD-run-01 归档，同日后续运行递增；报告注明对应配置和原始数据。未测量、失败和 OOM 单独说明。简短且清楚的 Mermaid 图可以留在 Markdown；内存格、矩阵与时间线使用统一图片。实测图放在对应实验目录，并保留生成代码和原始数据位置。

练习起点与个人结果分开；不创建空实验或假结果。资料准备、个人学习和运行验证分别记录。写“先看、动手、核对、卡住后回看”，不用角色化管理口吻。

## 图解怎样保存与检查

图片以首次使用的段号与概念命名，例如 `p01-function-call`、`w01-tensor-layout`；单卡训练诊断使用 `d01`，综合复习使用 `reviews`。同名 PNG 和 SVG 均由 `scripts/render_figures.py` 导出，正文嵌入 PNG，图注链接 SVG。跨课直接引用原图，不复制一份再分别修改。

每张图只回答一个主要问题。输入、计算、输出、搬运/通信、存储使用统一配色，并保留对象名称、箭头或线型；不能只靠颜色判断。内存图标元素位置和步长，时间线标事件、区间与单位；理论例子显式说明不是实测。轻手绘仅辅助比喻，不能代替精确数据流。

正文写描述性替代文本、简短图注、读图顺序和暂停题。关键公式和数字也保留在正文；图中示例不提前解答紧接着的独立题。外部机制在正文保留来源，不搬运整张课件或视频截图。

运行 `python scripts/render_figures.py` 导出全部图，也可在命令后追加图名。脚本明确选择微软雅黑或 Noto Sans CJK；缺字体、缺字形或文字超出画布时中止；SVG 统一使用 LF 且去除行末空白。使用 `--preview-dir` 指定仓库外的临时目录，可以生成 600 px 窄屏图与联系表；这些预览不重复纳入仓库。

每张新图都检查正常尺寸与窄屏预览，复核形状、数值、箭头、上下标、裁切和间距。脚本检查与视觉检查分别记录，材料状态写入覆盖表及带日期的核验记录；图片准备完成不修改个人学习状态。

## 核验与更新

首次进入、长期中断或接口变化时检查指定原始资料。记录访问日、课程年份或文档版本、代码 commit、指定范围和影响；本机版本按实测填写。视频的入口、字幕正文、画面时间轴分别记录，讲义函数不能冒充视频章节。

必学材料先检查全部指定内容和必要先修，再写中文导读、练习及核对依据。PDF 的图和公式按需检查；未读范围不标为已预读。找不到适合的视频时保留可独立完成的文字路径，说明缺项。更新同一日期记录可追加，跨日新增；已有实验保留原配置。

中文外部材料在原英文卡片与课页旁按需补充，完整来源放现有主题文件，保留原资源 ID；不建立第二套中文目录。优先原作者、原账号或官方中文，每个具体用途一个首选，额外来源须提供不同帮助。记录原创、对应译文或字幕视频的关系，给章节/函数起止、版本差异与未覆盖内容；入口可访问不代表正文、字幕或画面已检查。旧代码用于概念解释时写明停止点，不引入 FSDP1 等不匹配接口。

添加中文资料后，逐原资源 ID 登记部分覆盖或缺项；对比修改前后的英文 URL、指定范围、实验要求和个人进度。中文与英文讲解重复时不增加一轮必读或重复计时。核验结论放带日期记录，不能覆盖旧日期结论。

每次新建文档先确认现有文件是否已承担同一职责。所有旧文件移动或拆分均登记路径和锚点，并更新仓库引用；外部书签按迁移清单查找。完成后运行 `python scripts/check_docs.py` 与 `git diff --check`。检查脚本也检查链接标题误含锚点标记、上一课/下一课跳过 session；加学习段后同步课表与单元检查的返回入口。

## 发布与忽略

仅在明确要求提交或推送时执行。先检查当前分支、差异与暂存内容；只提交本次任务文件，远程有更新时先整合，使用普通推送，不覆盖远程历史。推送后比较本地提交与远程 SHA。

Markdown、原创图、代码、配置、小型真实数据与报告可纳入版本管理。虚拟环境、权重、checkpoint、大型 trace 和凭据按 .gitignore 排除；短日志保存可公开摘要。完整外部 PDF 和代码下载不放入课程目录；引用保留原始来源、版本和适用许可。许可证未选择时不预填授权声明。
